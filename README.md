# Carnicería Jesús Sanz — Click & Collect

Aplicación web Click & Collect desarrollada como TFG del Ciclo Superior de DAW.

## Descripción
Plataforma web para la Carnicería-Salchichería Jesús Sanz (Navas de Oro, Segovia) que permite a los clientes consultar el catálogo y realizar pedidos online para recoger en mostrador.

## Tecnologías
- PHP 8 + MVC
- MySQL / MariaDB
- Bootstrap 5
- Docker

## Acceso en producción
http://carniceriajesussanz.es

## Instalación en local
1. Clonar el repositorio
2. Ejecutar `docker-compose up -d`
3. Importar `database.sql` en phpMyAdmin (http://localhost:8081)
4. Acceder a http://localhost:8080
